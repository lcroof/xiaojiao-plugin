# 小脚一踩谁也不爱
根据白纸B站推送扩展<br>原项目地址 https://github.com/HeadmasterTan/zhi-plugin

## 安装
```base
git clone https://github.com/lcroof/xiaojiao-plugin.git ./plugins/xiaojiao-plugin/
```

## 功能
B站链接或转发的小卡片视频简介/转发/点赞/播放/时长等内容展示
<br>NGA链接帖子内容高赞和贴条展示
<br>支持以Cookie以账号登录态获取内容

## 帮助
发送 #小脚帮助 查看帮助面板
<br>支持锅巴插件（guoba-plugin）可视化配置
